# Проверки

| Что проверяется | Где |
| --- | --- |
| API-ключ для LOGIN, ACTION и LOGOUT; отказ не меняет сессию | `ApiKeyIT` |
| Токен из 32 символов A–Z0–9; границы длины и недопустимые символы | `TokenValidationIT` |
| Обязательные параметры и неизвестные действия | `TokenValidationIT` |
| Вход, действие, выход и повторный вход после выхода | `SessionLifecycleIT` |
| Независимость пользователей, в том числе при одновременных запросах | `SessionLifecycleIT` |
| POST, заголовки и токен в запросах к `/auth` и `/doAction` | `ApiTest.verifyCall` |
| Успешные и ошибочные ответы внешнего сервиса, разрыв соединения и восстановление | `ExternalServiceIT` |
| Тело внешнего ответа не влияет на результат | `ExternalServiceIT.ignoresExternalBody` |
| Повторные вход/выход, пробелы в названии действия и лишние поля | `AdditionalBehaviorIT`, допущения A4–A5 |
| Формат JSON и непустая причина ошибки | `ApiResponse` |

Точные HTTP-коды и дополнительные правила перечислены в [допущениях](../README.md). Проверки допустимого алфавита выявляют [NC-001](DEFECTS.md).
