# Допущения

- A1. Успешная операция возвращает HTTP 200 и `result: OK` без `message`. Неверные параметры — 400, отсутствующий или неправильный API-ключ — 401, действие без входа — 403. При ошибке ожидаются `result: ERROR` и непустой `message`; его точный текст не проверяется.
- A2. Любой ответ внешнего сервиса из диапазона 2xx считается успешным.
- A3. Ответ внешнего сервиса 4xx/5xx или разрыв соединения приводит к HTTP 500 и `result: ERROR`. Неудачный LOGIN не сохраняет токен. Ошибка ACTION не завершает уже открытую сессию.
- A4. Повторный LOGIN возвращает 409 и сохраняет действующую сессию. LOGOUT неизвестного или уже удалённого токена возвращает 403. В обоих случаях внешний сервис не вызывается.
- A5. Пробелы по краям `action` удаляются. Дополнительные поля запроса игнорируются.
- A6. Для допустимого LOGIN и разрешённого ACTION ожидается один запрос к нужному методу внешнего сервиса с тем же токеном. Число повторов при разрыве соединения не фиксируется.

Время ответа приложения в задании не указано. Ограничения ожидания в тестах используются только для завершения зависшего запуска.
