## Причина трёх падений

По требованиям допустимы все символы A-Z0-9. Токены `G` × 32, `Z` × 32 и `ABCDEFGHIJKLMNOPQRSTUVWXYZ012345` отвергаются с HTTP 400; сообщение указывает на regex `^[0-9A-F]{32}$`. Это три примера одного дефекта, а не три разных дефекта. Проверки продолжают ожидать успешную авторизацию согласно заданию.

Подробности и воспроизведение: [DEFECTS.md](docs/DEFECTS.md).

## Понятность и корректность отчёта

- Основной отчёт автоматически сформирован из 147 результатов Allure; счётчики совпадают с первичными XML: 144 успешны, 3 расхождения, 0 без результата.
- В отчёте есть пять групп возможностей, все 147 раскрываемых сценариев и три понятных примера одного дефекта: ожидание, фактический результат и последствие для пользователя.
- Термины пояснены, программные имена методов не показываются в основной сводке. HTTP-коды, JSON и журналы доступны в подробном Allure.
- В Chrome проверены вид на широком экране и ширина 375 px, отсутствие горизонтального переполнения, раскрытие списка сценариев, локальная ссылка в Allure и читаемые сообщения о падении. Ошибок JavaScript нет.
- На отдельных входных данных проверено, что генератор правильно учитывает failed/skipped/broken, экранирует HTML и отклоняет пустые результаты и смешанные повторные запуски. Эти проверки генератора не включены в число 147 проверок приложения.
